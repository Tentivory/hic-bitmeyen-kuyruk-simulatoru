# Hıç Bitmeyen Kuyruk Simülatörü

## Özet
Bu proje, insanlığın en büyük başarısıdır. Binlerce yıllık kuyruk geleneğini tek bir Python dosyasına sığdırdık. Artık evden çıkmadan, çayını demlemeden, hayatını yaşamadan sonsuz kuyruk deneyimini yaşayabilirsin. Bilim insanları bu kodu incelediğinde ağladı. Çünkü çok gerçekti.

## Neden Bu Proje?
Çünkü kuyruk bitmez. Bitmez. Asla bitmez. Bu simülatör bunu kanıtlar. Önünde hep birileri vardır. Sıra sana gelmez. Gelirse de 'bir şeyler eksik' derler. Bu kod, o 'bir şeyler eksik' hissini matematiksel olarak modellemiştir.

## Nasıl Çalıştırılır?
```bash
python kuyruk.py
```

**UYARI:** Bu programı çalıştırdıktan sonra hayatını sorgulayabilirsin. Önerilmez. Ama önerilir. Çünkü kuyruk beklerken düşünmek iyidir.

## Özellikler
- Sonsuz döngü (gerçekten sonsuz)
- Rastgele bekleme süreleri (1 saniye ile 1 asır arası)
- Önündeki kişi sayısı asla azalmaz
- Bazen 'sıra sende' der ama hemen pişman olur
- Çay molası simülasyonu (kuyrukta beklerken)

## Bilimsel Katkı
Bu proje, 'kuyruk teorisi'ni yeniden yazmıştır. Artık kuyruk bitmez diye bir teorem vardır. Kanıtı: Bu kod.

## Lisans
Kuyruk beklerken lisans okuyamazsın. Zaten okuma.
